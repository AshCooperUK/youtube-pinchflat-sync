Output Template Syntax

You can mix Liquid-style variables, yt-dlp-style variables and normal folder names in the same path.

Liquid-style /{{ '{{ channel }}' }}/{{ '{{ title }}' }} - {{ '{{ id }}' }}.{{ '{{ ext }}' }} yt-dlp-style /%(channel)s/%(duration>%H-%M-%S)s-%(id)s.%(ext)s Bare folders and Liquid-style /videos/1080p/{{ '{{ id }}' }}.{{ '{{ ext }}' }}

Your template must end with an extension option such as .{{ '{{ ext }}' }} or .%(ext)s.
