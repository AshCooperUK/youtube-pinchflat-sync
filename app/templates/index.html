Output Template Help

Pinchflat output-path syntax and useful template variables.

Output Template Syntax

You can mix Liquid-style variables, yt-dlp-style variables and normal folder names in the same path.

Liquid-style /{{ '{{ channel }}' }}/{{ '{{ title }}' }} - {{ '{{ id }}' }}.{{ '{{ ext }}' }} yt-dlp-style /%(channel)s/%(duration>%H-%M-%S)s-%(id)s.%(ext)s Bare folders and Liquid-style /videos/1080p/{{ '{{ id }}' }}.{{ '{{ ext }}' }}

Your template must end with an extension option such as .{{ '{{ ext }}' }} or .%(ext)s.

Media Center Custom Aliases

  • {{ '{{ season_by_year__episode_by_date }}' }} → Season YYYY/sYYYYeMMDD
  • {{ '{{ season_by_year__episode_by_date_and_index }}' }} → recommended. Handles date collisions with an index.
  • {{ '{{ static_season__episode_by_index }}' }} → Season 1/s01eXX. Best for playlists that do not change.
  • {{ '{{ static_season__episode_by_date }}' }} → Season 1/s01eYYMMDD.
