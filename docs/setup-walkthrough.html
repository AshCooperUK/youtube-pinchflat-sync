STEP 03 / EDIT BEFORE DOCKER STARTS

Set your public URL in YAML

Edit compose.yaml or the YAML imported into your Docker dashboard.

Relevant service settings

environment:
  APP_URL: "https://youtube.example.com"
  CANONICAL_REDIRECT: "true"
  GOOGLE_REDIRECT_URI: ""
ports:
  - "8787:8787"
volumes:
  - /srv/ytsd/data:/data
  - /srv/media/youtube:/downloads
Replace the example domain and paths. On upgrades, keep your existing /data and /downloads mounts.
Leaving GOOGLE_REDIRECT_URI blank derives the callback from APP_URL.
Google callback example: https://youtube.example.com/oauth/google/callback
