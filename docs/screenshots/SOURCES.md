# Setup screenshot sources

`setup-create-tunnel.jpg` and `setup-route.jpg` are still screenshots from Cloudflare's public “How to set up Cloudflare Tunnel” tutorial, embedded in its [Create a tunnel documentation](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/). Captured on 20 September 2026 to identify the tunnel and published-hostname controls. Cloudflare provides the example account and domain shown in the video. No YTSD user's account or configuration is pictured.

The screenshots contain Cloudflare interface and tutorial content, © Cloudflare. They are attributed instructional excerpts, not original YTSD artwork. Follow the YTSD README's values for the hostname, blank path, HTTP protocol and port 8787.
